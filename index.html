这里收集了社区为 FoloToy AI Passport（ESP32-C3）做的有趣玩法。点任意玩法的「安装」，按提示用数据线连上设备，就能在浏览器里直接刷入——不需要装任何软件。

  • 🔒 安装只写入设备的应用区（factory 分区），不触碰设备身份（cardid）与官方恢复区（Recovery），随时可长按 UP 开机进 Recovery、用官方小程序装回官方玩法。
  • 🖥️ 在线安装需要桌面版 Chrome 或 Edge（Web Serial），安卓版 Chrome 没有这个接口。
  • 📱 安卓手机可以点卡片上的「下载固件 .bin」，再用 OTG 数据线 + 安卓 ESP32 刷机 App，把固件写到地址 0x10000 完成安装。
  • ⚠️ 安装会替换设备当前玩法；个别玩法原有的存档/设置可能会被重置。

⚠️ 当前浏览器不支持 Web Serial，无法在线安装。请使用桌面版 Chrome / Edge 打开本页。

安装玩法

  1. 先关机，然后按住设备上的 UP 键不松手，再插入数据线开机，直到电脑识别出串口（设备进入下载模式）。
  2. 点下方「连接设备」，在浏览器弹窗里选择对应的串口（名字里通常带 USB / JTAG 字样）。
  3. 连接成功后点「开始安装」，全程不要拔线，装完设备会自己重启。
